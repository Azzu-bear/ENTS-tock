# Starting Contributions in jLab
1. Contact John Madden (Maintainer) to add user to dev server
    a. Provide public ssh key and public email
2. SSH in with provided login name and ip
3. Run `./check_tools.sh`
    a. If packages are not installing, try `pipx ensurepath`
4. Run `git config --global user.name "Your Name"
5. Run `git config --global user.email "Your Email"`
